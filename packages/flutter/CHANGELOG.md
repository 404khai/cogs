## 0.1.0

- First release. `Cog` and `CogPainter` paint all 20 chassis, 12 expressions and 8 display modes, ported from the web studio.
- Live eyes: expressions tween, gaze follows the pointer and wanders, blinks run on the unit's own schedule.
- Cog JSON (`cogs/unit@1`): `parseCog` with per-field warnings, `CogConfig.toJson` / `fromJson`, share-link payloads and serials that match the studio.
